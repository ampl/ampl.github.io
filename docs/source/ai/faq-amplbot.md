# FAQ: AMPL for ChatGPT

## What is AMPL for ChatGPT?

AMPL for ChatGPT is a specialized AI assistant for optimization modeling with AMPL and AMPL+Python workflows, available as a custom GPT on ChatGPT.

It helps you learn AMPL, draft models from natural language, debug formulations, and build optimization applications with `amplpy`.

## Is AMPL for ChatGPT free?

Yes. You can access it here: [AMPL for ChatGPT](https://l.ampl.com/https://chatgpt.com/g/g-68c00de8b030819185be6db190ad7bce-amplbot).

## What can AMPL for ChatGPT help me with?

AMPL for ChatGPT supports the full modeling lifecycle:

* Learn AMPL syntax, installation basics, and modeling patterns.
* Formulate LP, MIP, NLP, MINLP, CP, and multi-objective models from plain-language descriptions.
* Build AMPL+Python applications and data pipelines using `amplpy`.
* Diagnose infeasibility, unboundedness, and solver errors.
* Improve performance with reformulations and solver-option guidance.

## What makes AMPL for ChatGPT different from other LLMs?

AMPL for ChatGPT is focused on AMPL and optimization workflows. It is designed to produce practical AMPL and `amplpy` guidance for modeling, debugging, and deployment-oriented use cases.

## How do I get started with AMPL for ChatGPT?

Open [AMPL for ChatGPT](https://l.ampl.com/https://chatgpt.com/g/g-68c00de8b030819185be6db190ad7bce-amplbot) and start with prompts like:

> "Quick guide on how to use AMPL"

or

> "Help me formulate this optimization problem in AMPL and build a Python app around it."

## Is AMPL for ChatGPT able to help with complex models?

Yes. It is useful for large and complex models, but it is still important to validate assumptions and test the resulting model carefully.

## Does AMPL for ChatGPT execute optimization code?

No. AMPL for ChatGPT helps you model and write code, but it does not run your optimization jobs.

## Do I need AMPL installed to use AMPL for ChatGPT?

No. You can use AMPL for ChatGPT directly in ChatGPT without a local AMPL installation.

## Is AMPL for ChatGPT always accurate?

AMPL for ChatGPT is often effective for AMPL-related tasks, but like any LLM it can make mistakes. Review outputs critically, especially for production use.
