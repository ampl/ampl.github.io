- [Gemini Notebook for AMPL](notebooklm.md): a grounded notebook that answers only from official AMPL documents, with inline citations.
- [AMPL for ChatGPT](amplbot-chatgpt.md): AMPL's optimization assistant inside ChatGPT, available as a custom GPT.
- [AMPL for Gemini](gemini-assistant.md): AMPL's optimization consultant inside Google Gemini, available as a custom Gem.

All of these include AMPL-specific knowledge, but hallucinations and incorrect responses may still occur. Always validate generated models, code, and recommendations. For a comparison with the other AMPL AI tools, see [Which tool should I use?](index.md#which-tool-should-i-use).
